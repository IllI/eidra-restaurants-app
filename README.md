# Welcome to Eidra's Munchies! For all your restaurant needs!

Eidra's Munchies! is an API-driven Next.js application that helps our users find the right restaurant for them.

![Eidra's Munchies Application](public/assets/images/application.png)

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
